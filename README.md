📌 Tentang Proyek
In the Kost merupakan sistem informasi yang dirancang untuk mempermudah pencarian dan pengelolaan tempat tinggal atau kost melalui perangkat mobile dan web.

Pengguna dapat mencari kost berdasarkan lokasi, harga, fasilitas, dan jenis kost. Selain itu, pengguna dapat melihat informasi kost serta menghubungi pemilik secara langsung melalui telepon atau WhatsApp.

Sistem ini juga menyediakan fitur pengelolaan data kost untuk admin atau pemilik.

🎯 Tujuan
Mempermudah pencarian tempat tinggal.
Menyediakan informasi kost yang jelas dan terstruktur.
Memudahkan komunikasi antara pencari kost dan pemilik.
Membantu pengelolaan data kost secara digital.
Menerapkan teknologi mobile, web, dan basis data.
✨ Fitur Utama
🔍 Pencarian dan Filter
Pencarian berdasarkan lokasi.
Filter rentang harga.
Filter fasilitas.
Pilihan jenis kost: putra, putri, dan campur.
🏡 Informasi Kost
Galeri foto kost.
Informasi alamat dan harga.
Daftar fasilitas.
Informasi ketersediaan kamar berdasarkan data sistem.
📞 Kontak Pemilik
Menghubungi pemilik melalui telepon.
Mengirim pesan melalui WhatsApp.
⚙️ Dashboard Admin dan Pemilik
Menambahkan data kost.
Melihat daftar kost.
Mengedit informasi kost.
Menghapus data kost.
📱 Antarmuka Responsif
Tampilan dirancang agar dapat menyesuaikan ukuran layar perangkat yang didukung.

🚀 Cara Menjalankan Proyek
1. Clone Repository
git clone https://github.com/Mozithol/in-the-kost.git
Masuk ke direktori proyek:

cd in-the-kost
2. Jalankan Aplikasi Flutter
Masuk ke direktori yang berisi file pubspec.yaml, kemudian jalankan:

flutter pub get
flutter run
Pastikan Flutter SDK dan perangkat atau emulator telah tersedia.

3. Konfigurasi Backend
Jalankan Apache dan MySQL melalui XAMPP atau web server yang digunakan.
Tempatkan source code PHP pada direktori web server.
Buat database MySQL sesuai konfigurasi proyek.
Impor file SQL jika tersedia.
Sesuaikan konfigurasi koneksi database.
Pastikan REST API dapat diakses oleh aplikasi.
Catatan: Sesuaikan direktori, nama database, dan alamat API dengan konfigurasi aktual proyek.
